## Blender 相机匹配流程

1. 在照片上标出至少 6 个可辨识点：楼角、屋檐线、窗格线、入口柱和地平线。
2. 先匹配相机高度、水平视场和建筑旋转，再调整模型尺寸；不要用拉伸模型去补偿透视误差。
3. 使用未被树木、人物、标语遮挡的结构线做误差判断。
4. 保存每组相机为 `CAM_F01_MainSouth` 这类固定名称，记录调整日期和已知缺口。
5. 导出 UE 对比图时保持相同画幅与近似视场，所有偏差写入 `docs/qa/visual-review.md`。

# 校园布局决策与待核实项

更新时间：2026-09-07。此文件把照片位置匹配表、素材清单、分布图 v2 和旧 Three.js 坐标分开记录。照片证据优先于旧代码中的估计尺寸；没有证据的区域保持可替换体块。

## 当前采用的坐标约定

- Blender/UE 统一使用米建模；UE 导入后 1 Blender 单位 = 1 cm 的转换规则需在导入样例中锁定。
- 平面坐标：X 向东，Y 向上，Z 向南；北为负 Z，校门暂定在南侧。
- 旧项目坐标仅作为交互点和相对关系参考，不能作为测量数据。旧代码中的校门约 z=94、主广场约 z=44，属于待重新校准的线索。

## 样板尺寸策略

主楼入口、台阶、雨棚和外廊先使用照片比例建立相对尺寸；在没有实测或门窗标准物作为尺度锚点前，不标注为真实米数。每个建筑资产保留可调整的参数：楼层高度、窗格间距、翼楼长度、走廊深度、入口宽度和立面分格。

## 进入最终建模前要补的证据

1. 校门正面与门内视角照片。
2. 主楼背面、楼栋之间连廊和办公楼/实验楼相对位置。
3. 篮球场数量及在校园中的方位。
4. 花园水池方向、凉亭与荷花塘关系。
5. 目标还原年份，以及是否保留当年标语、植物和灯具。

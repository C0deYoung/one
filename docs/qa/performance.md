# 性能测试记录

目标：在阶段 A 选定的实际测试电脑上，以 1080p 为起点记录完整路线和重负载位置。60 FPS 是目标，不是未经测试的保证。

## 测试点

- 校门进入主路。
- 主广场正面朝主楼。
- 主楼入口近景与外廊。
- 花园植物、水池和凉亭。
- 球场/红色拱门区域。
- 夜景或晚自习灯光（加入后）。

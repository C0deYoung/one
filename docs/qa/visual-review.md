# 视觉还原复核表

每次样板或楼栋资产更新后，使用固定相机导出图像，并把结论写入本文件或链接到带日期的截图目录。

## 对比维度

- [ ] 主楼轮廓、楼层高度和两翼长度符合 F-01。
- [ ] 入口塔楼宽度、绿玻璃分格、校徽与立体字位置符合 F-01。
- [ ] 侧面厚度、外廊深度、柱距和蓝饰带符合 F-02/F-03。
- [ ] 窗户数量与照片可见范围相符；遮挡区域没有凭空添加细节。
- [ ] 材质区分瓷砖、玻璃、混凝土、金属；不会出现整张照片的树影/人物投影贴在墙上。
- [ ] 台阶、门洞、栏杆、走廊具有真实深度，并且玩家能正常通过。
- [ ] 日光、阴影和曝光保持稳定；Lumen 开关前后没有明显错误反射。
- [ ] 正面、斜侧、近景和玩家视角都成立。

## 记录格式

```text
日期：YYYY-MM-DD
资产/地图：
参考镜头：F-01 / F-02 / ...
通过项：
偏差：
偏差等级：阻断 / 高 / 中 / 低
下一步：
证据：deliverables/screenshots/...
```

## 阻断条件

如果正面照片只能靠整张平面贴图伪装，侧面没有立体结构，或主要比例明显不符，则样板未通过，暂停批量扩建并返回 Blender 修正。

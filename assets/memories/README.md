# 在这里放入你的老照片！

把老照片按下面的文件名放进本目录，游戏里的回忆卡片就会**自动展示**它们，无需改任何代码：

| 文件名 | 对应回忆点 | 建议放什么 |
|--------|-----------|-----------|
| `01.jpg` | 开学报到（校门口） | 校门口的合影、报到那天的照片 |
| `02.jpg` | 升旗仪式（旗杆/广场） | 升旗、课间操、全校集会 |
| `03.jpg` | 光荣榜（宣传栏） | 成绩单、光荣榜、奖状 |
| `04.jpg` | 课间十分钟（大树下） | 同学在树下/走廊的抓拍 |
| `05.jpg` | 通往操场的路（红色拱门） | 运动会、体育课、红色拱门老照片 |
| `06.jpg` | 放学后的球场（篮球场） | 篮球赛、球场合影 |
| `07.jpg` | 教室与晚自习（教学楼） | 教室、晚自习、毕业照、倒计时牌 |

- 支持 `jpg / png`（png 请相应改名为 `01.png` 等，或直接把代码里 `'.jpg'` 改掉）
- **2015 年以前的翻拍照片效果最好**——手机翻拍老相册时关掉闪光灯、找自然光
- 收集齐 7 段回忆后的结局画面，目前用的是 `assets/reference/campus-aerial.jpg`（你提供的校园航拍），
  也可以换成一张老毕业照：把它命名为 `assets/reference/ending.jpg` 并修改 `index.html` 里
  `<img id="endImg">` 的 `src` 即可。

## 老照片哪里找（2015 年以前）

1. **校友群 / 班级群**：1998–2014 届的班级群是老照片最集中的地方
2. **百度贴吧「郧西一中吧」**：翻 2010–2016 年的老帖，有不少毕业照求助/分享帖
3. **学校校史征集**：郧西一中 2018 年曾公开向校友征集校史文物和老照片
   （搜狐有倡议书），可联系学校办公室 0719-6227489 询问校史室藏照
4. **抖音**：搜「郧西一中」话题，本地号（如抖音号 15637078）发过校园影像；
   高考季郧西融媒体也会放出校园航拍
5. **老毕业纪念册**：毕业纪念册同学录扫描件是最有"味道"的素材
